Maintenance

Auto Backup

Mails a full backup of the entire spreadsheet (every table, Material Submittal Status, and team settings) as an Excel file to the address below, sent through your own Google account. "Send Backup Now" sends one immediately. The periodic schedule is checked each time an Admin opens this app — it fires on the next time someone with Admin access opens it at or after the interval, not at an exact clock time, since there is no server running in the background here.

Scheduled Status Report

Mails the same PDF as "Export Status Report (PDF)" (Status of PQD, Status of Material Submittal, and Item/Buyer) to the address below, sent through your own Google account. "Send Report Now" sends one immediately. The periodic schedule is checked each time an Admin opens this app, the same way Auto Backup is.
