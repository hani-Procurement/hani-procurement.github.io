Tables

Add, rename, or remove the BOQ tables shown in Full Table. Each table is fully independent (its own items), and its name also appears as the Discipline when that table is selected.

Auto Backup

Mails a full backup of the entire spreadsheet (every table, Material Submittal Status, and team settings) as an Excel file to the address below, sent through your own Google account. "Send Backup Now" sends one immediately. The periodic schedule is checked each time an Admin opens this app — it fires on the next time someone with Admin access opens it at or after the interval, not at an exact clock time, since there is no server running in the background here.

Invite link

Send this link to a teammate after adding them below. It opens this same team sheet directly — without it, their sign-in would try to create a separate sheet of their own.

Team members & permissions

Control exactly who can add items, delete items, reorder/move items, or change status fields (Action By, Comp. Sheet Status, PQD/M/S Submitted & Code). Everyone can still view everything and edit the regular fields.
